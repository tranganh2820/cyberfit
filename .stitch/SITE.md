# SITE: CyberFit

## 1. Vision
A high-intensity, social-driven fitness tracking SaaS. The UI is characterized by a "Cyber/Intense" aesthetic: dark backgrounds, neon accents, and sharp geometry.

## 2. Project Metadata
- **Stitch Project ID:** 1540943495340383425
- **Design System:** `.stitch/DESIGN.md`

## 3. Tech Stack
- **Frontend:** React + Tailwind CSS
- **Design:** Stitch MCP
- **Icons:** Lucide React (Cyber-styled)

## 4. Sitemap
- [x] **Dashboard** (`index`) - Core metrics, quick log, and activity summary.
- [x] **Leaderboards** (`leaderboards`) - Global and friend rankings with biometric comparisons.
- [x] **Routine Builder** (`routines`) - Technical interface for sequences.
- [x] **Nutrition Tracker** (`nutrition`) - Macro logging and history.
- [x] **Subscriptions** (`premium`) - Tier selection and Stripe integration.

## 5. Roadmap
1. Generate high-fidelity designs for all core screens.
2. Implement React scaffold and design system tokens.
3. Componentize Stitch designs into modular React components.
4. Integrate logic and mock data.

## 6. Creative Freedom / Ideas
- **Biometric HUD Overlay**: For real-time workout tracking.
- **Achievement Terminal**: A dedicated page for unlocked badges.
- **Cyber-Coach AI**: A stylized chatbot interface for advice.
